# Sistema de agendamentos para barbearia

Projeto em desenvolvimento para praticar Python, PostgreSQL e modularizacao.

## Funcionalidades atuais

- Cadastro de barbeiros
- Criacao automatica de disponibilidade padrao
- Consulta de barbeiros
- Alteracao de horarios de disponibilidade

## Proximos passos

- Criar cadastro de clientes
- Criar agendamentos
- Melhorar organizacao dos modulos
- Validar melhor os dados
- Criar interface grafica ou web
